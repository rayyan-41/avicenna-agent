# AVICENNA.md

This file has been superseded. The repository's doctrine, architecture,
conventions and style rules now live in one canonical document:

- **[AGENTS.md](AGENTS.md)** — what Avicenna is for, why it is built this way,
  how subagents and MCP tools extend it, and the conventions every contributor
  and coding agent is held to.
- **[CLAUDE.md](CLAUDE.md)** — the short operational layer for Claude Code:
  where things live, which commands to run, and the rules that bite.

Note the distinction that both files open with: the `AGENTS.md` at the *repo*
root is development doctrine, while the `AGENTS.md` at a *vault* root is the
runtime orchestrator protocol for that user's vault. They are different files
and neither is ever renamed to `AVICENNA.md`.
